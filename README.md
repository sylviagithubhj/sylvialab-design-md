## 문서 구성

디자인 시스템은 **원칙 + 토큰 + 컴포넌트 + 사용 규칙 + 구현·검증**의 묶음입니다. 여기 DESIGN.md는 그것을 사람과 AI가 바로 참조할 수 있게 한 파일로 줄인 요약입니다. 디자인 시스템 전체를 대신하지는 않습니다.

- 맨 위 **YAML 토큰**: 색, 글자, 모서리, 간격, 핵심 컴포넌트 값. 도구와 AI가 그대로 읽습니다. 확인된 값만 넣습니다.
- 아래 **13개 장**: 개요와 원칙 → 색상 → 타이포그래피 → 레이아웃·간격 → 모서리·고도·모션 → 컴포넌트(변형·상태) → 패턴 → 접근성(대비 계산) → 글쓰기 톤 → Do & Don't → 구현·운영 → AI에 넣을 때 → 참고 자료
- 관찰로 쓴 문서의 원칙과 Do & Don't는 화면에서 반복되는 규칙을 SylviaLab이 정리한 것입니다(공식 규칙 아님). 문서마다 그렇게 표시합니다.

틀은 [TEMPLATE.md](TEMPLATE.md)에 있습니다.

## 사용법

1. 원하는 서비스의 `DESIGN.md`를 엽니다.
2. 내용을 통째로 Claude에 붙여 넣거나, 9장 "AI에 넣을 때"의 요약만 넣습니다.
3. "이 디자인 시스템으로 ○○ 화면을 만들어 줘"라고 요청합니다.

## 상표 안내

서비스 이름은 각 회사의 상표이며, 어떤 서비스를 정리했는지 알리는 용도로만 씁니다. 로고는 넣지 않았습니다. 이 저장소는 각 회사와 관계가 없습니다.
